# 한·일 단어장 · 韓日単語帳

한국어 ⇄ 日本語 기초 단어장 사이트입니다. 한국인은 일본어를, 日本人は韓国語を 같은 단어장으로 공부합니다.
서버나 설치가 필요 없는 정적 사이트라서, 이 저장소의 파일이 그대로 사이트가 됩니다.

## 기능
- 오늘 학습: 새 단어 → 떠올리기 → 모름/애매함/알아요 평가, 1·3·7·14·30·60일 간격 복습
- 하루 학습량: 오늘 목표와 진행률, 연속 학습일, 최근 7일 기록
- 예문 속 단어 강조, 후리가나, 한글 발음 / カタカナ読み, 발음 듣기
- 퀴즈: 뜻 고르기, 단어 고르기, 읽기 고르기 (학습한 단어 / 틀린 단어 / 분류별)
- 단어 목록: 검색, 분류·진도별 보기, 한국어/일본어 가리기로 서로 문제 내기
- 설정: 하루 새 단어 수, 문제 방향, 글자 크기

## 파일 구성
- `index.html` — 화면과 학습 기능
- `words.js` — 단어 데이터 (단어를 추가·수정할 때는 이 파일만 바꾸면 됩니다)
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — 휴대폰 "홈 화면에 추가"용

## 알아둘 점
- 진도는 각자 쓰는 브라우저에 저장됩니다. 다른 기기에서는 처음부터 시작해요.
- 발음 듣기는 기기에 들어 있는 음성을 씁니다. 일본어·한국어 음성이 없는 기기에서는 소리가 안 날 수 있어요.
- 수정한 파일을 올리면 1~2분 뒤 같은 주소에 반영됩니다. 이미 열어 둔 브라우저는 최대 10분쯤 예전 화면이 보일 수 있어요.
